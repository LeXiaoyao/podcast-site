本期要点

  • Anthropic发布Claude Opus 4.7，在SWE-bench和智能体推理测试中超越GPT-5.4与Gemini 3.1 Pro，巩固其在复杂编程与推理场景的领先地位。
  • OpenAI战略负责人Dresser在内部备忘录中承认，Anthropic在编程方向的专注“给了他们早期的楔子”，公司正加速向企业客户转型。
  • Meta发布一款达到Opus级别新模型，同时收购Dreamer和Manus两家公司；该模型不开源、不提供API，目标是构建面向专业用户的AI操作系统。
  • Anthropic宣布进军伦敦知识区，计划设立800人规模团队；OpenAI亦于近日在伦敦开设首个永久办公室。
  • 微软在GitHub发布Agent框架多个Beta更新，版本号从1.0 beta起步。
  • 欧盟《数字市场法》正式将AI聊天机器人纳入搜索竞争范畴，要求谷歌向OpenAI、Anthropic等AI助手开放搜索数据访问权限。
  • Google Labs发布Gemini for Mac原生客户端，全部用Swift编写，不到100天内上线100多项功能。
  • OpenAI发布AI对就业影响研究报告，指出约18%的职业面临较高自动化风险，约12%的职业可能因AI而扩张。
  • AMD股价昨日上涨6%，发生在5月财报发布前，主要受数据中心需求预期持续支撑。

研究底稿

开场角度

Meta内部调整、微软开源框架、欧盟监管新规，今天AI圈动静不小。

今天先抓这几件事

  • Meta高管搬进AI团队，亲自参与开发
  • 微软发布多款Agent框架，开源生态再添新成员
  • 欧盟将AI聊天机器人纳入搜索数据共享监管

推荐播报顺序

01. Meta高管搬进AI团队

这条讲什么： 扎克伯格搬进AI团队办公室，与Alexandr、Nat同住，亲自参与编码，Llama 4发布后团队反而增加招聘。

为什么现在讲： 高管亲临一线，显示Meta对AI业务的重视程度升级，内部调整可能影响后续产品节奏。

主播怎么接： 说完Meta的内部动向，再看微软在开源领域的动作。

02. 微软开源Agent框架

这条讲什么： 微软在GitHub发布agent-framework系列，包括与Anthropic、Azure、Bedrock等集成的多个组件。

为什么现在讲： 微软通过开源框架降低AI应用开发门槛，推动多模型Agent生态，开发者可快速集成主流AI服务。

主播怎么接： 开源安全方面，GitHub也有新进展。

03. GitHub开源安全研究框架

这条讲什么： GitHub Security Lab发布Taskflow Agent，开源框架用于AI驱动的安全研究协作。

为什么现在讲： 针对AI在安全领域的应用，提供标准化工具，帮助研究人员更高效地发现和修复漏洞。

主播怎么接： 监管层面，欧盟对AI搜索功能有了新要求。

04. 欧盟监管AI搜索功能

这条讲什么： 欧盟要求Google向竞争对手共享搜索数据，新规明确涵盖具有搜索功能的AI聊天机器人。

为什么现在讲： 监管机构将AI聊天机器人视为传统搜索的竞争者，可能影响Google、OpenAI等公司的数据策略。

主播怎么接： 最后提醒一下，投资市场对AI芯片的关注度持续升温。

05. AMD股价上涨6%

这条讲什么： AMD股价在5月财报前上涨6%，市场关注其AI芯片能否挑战NVIDIA。

为什么现在讲： 投资者期待AMD在AI芯片市场取得突破，财报可能披露更多订单或技术进展。

主播怎么接： 以上就是今天的主要动态。

收尾提醒

总结一下，从公司战略到开源工具，再到监管政策，AI领域正在多线推进。
